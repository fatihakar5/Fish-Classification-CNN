# Fish Species Classification with Deep Learning
This project focuses on the classification of fish species using deep learning techniques, specifically Convolutional Neural Networks (CNN). The model was built using Keras and TensorFlow to automatically classify images of fish into one of nine distinct species.

![FISH](https://github.com/user-attachments/assets/0caca819-9bf2-4bec-a255-40337f751ba3)


## Dataset
The dataset used in this project is sourced from Kaggle's [Large-Scale Fish Dataset](https://www.kaggle.com/datasets/crowww/a-large-scale-fish-dataset), which contains a large number of images categorized into 9 different fish species. This dataset provides a rich set of labeled images, ideal for training deep learning models.

## Project Overview
The goal of this project was to develop a model capable of classifying fish species with high accuracy. After training and fine-tuning the model, we evaluated its performance using several metrics. To further explore the dataset, various visualizations were created to better understand the model's behavior and the distribution of species.

## Visualizations
1. Fish Species Image Samples:
A random selection of 15 images from the test set was visualized. Each image is displayed with both its true label and the predicted label by the model. This provides a clear view of how the model performs on real data and highlights potential areas for improvement.

2. Fish Species Distribution:
To understand the balance of the dataset, a count plot was generated to show the distribution of the 9 fish species. This visualization reveals how many images belong to each species, which is helpful for identifying any potential class imbalances that could impact model performance.

3. Fish Species Examples:
This visualization shows example images of the 9 different fish species in the dataset, along with their respective labels. It provides a direct view of the images used in training the model and can help in understanding how the model differentiates between the species.

## Conclusion
This project highlights the power of deep learning, specifically CNNs, in solving image classification problems. By leveraging Keras and TensorFlow, we built an effective model for classifying fish species. The visualizations provide valuable insights into the data distribution and the model’s performance, making this project a great example of real-world applications of deep learning.
